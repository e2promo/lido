# Безопасность

- Никогда не добавляйте в репозиторий `.env`, ключи ВКонтакте, токены GigaChat/YandexGPT/OpenAI и секреты Telegram. Файл `.env` исключён через `.gitignore`.
- Если ключ был опубликован (в чате, скриншоте или коммите) — перевыпустите его в личном кабинете провайдера.
- В Vercel задавайте только `BACKEND_URL`. Секреты модели и ВК задаются **на бэкенде** (Render/Railway/VPS) в переменных окружения.
- Webhook ВКонтакте защищён секретным ключом (`VK_SECRET`). Используйте HTTPS.
- Для каждого сообщества ВК используйте отдельный `slug` в адресе webhook: `/webhook/vk?org=<slug>`.
- Пользовательские данные хранятся в постоянном хранилище бэкенда (`DATA_DIR`), а не в serverless-функции Vercel.

О проблемах и уязвимостях сообщайте приватно через GitHub Security Advisories.
